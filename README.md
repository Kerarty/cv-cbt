# Резюме-карта АБС — интерактивное резюме для «Инженер-программист» (ЦБТ)

**Смотреть:** [kerarty.github.io/cv-cbt](https://kerarty.github.io/cv-cbt/) ·
PDF для HR — кнопка «PDF / печать» в шапке.

Отклик на вакансию **«Инженер-программист»**, ОАО «Центр банковских технологий»
([cbt.by/career](https://www.cbt.by/career/)).

## Зачем

Вакансия просит C# и Java, React, отладку разработанного ПО и участие в проектной/
эксплуатационной документации. Поэтому резюме собрано как демонстрация именно этого:
страница — **живая схема автоматизированной банковской системы**, где каждый узел
(шлюз, шина, ядро, платёжный процессинг, DWH, АФЛ, ИБ, мониторинг, документация) —
зона ответственности из постановки вакансии, а кандидат — «модуль MOD-ENG-324403»
со статусом **не подключён**. Форма отвечает содержанию: документ сам спроектирован
по принципам, которые декларирует, — слои данных, типизация, основная надпись по ГОСТ,
healthcheck вместо самопохвалы.

## Что внутри

- **Конфигурация системы** — SVG-карта АБС с ортогональной трассировкой связей,
  дугами-перемычками на пересечениях и штриховкой слоёв; клик по узлу открывает панель:
  проблема узла → чем её закрывает кандидат → проекты-доказательства.
- **Healthcheck** — построчная диагностика «конфигурации»: 10/11 узлов отвечают,
  модуль инженера не подключён — механика ведёт к отклику.
- **Ведомость соответствия** — требование вакансии → честный уровень (1–5) →
  доказательство; наведение на строку подсвечивает узлы карты, где навык применяется.
- **Реестр модулей** — 8 паспортов проектов: стек, архитектурные решения, автотесты,
  ссылки на исходники.
- **Журнал операций** — хронология в формате op-log: инициализация (БГУИР),
  сборки, релизы, заявка на подключение.
- **Заявка на подключение** — акт соответствия требованиям, mailto-отклик в HR с
  заготовленным текстом, контакты с копированием в один клик.
- **Fallback** — print/PDF-версия всех разделов для HR, `prefers-reduced-motion`,
  управление с клавиатуры и ARIA на интерактивных узлах схемы.

## Каноны (как в предыдущих резюме-проектах)

- React 19 + TypeScript + Vite; ноль сетевых запросов в рантайме — шрифты ParaType
  собраны локально (`@fontsource`), SVG-карта без внешних библиотек;
- HR нельзя проиграть: все разделы в одной прокрутке, печать — полный статичный
  фоллбек документа;
- все числовые факты проверяемы — источник:
  [github.com/Kerarty](https://github.com/Kerarty);
- политика честности: только проверяемый опыт — Spring и ASP.NET не приписываются,
  дипломный проект описан без ссылки (репозиторий приватный).

## Запуск

```bash
npm install
npm run dev      # локальный запуск
npm run build    # прод-сборка (tsc -b && vite build)
npm run preview  # предпросмотр сборки
npm run lint     # oxlint
```

## Деплой

Пуш в `main` → GitHub Actions: сборка → GitHub Pages (`base: /cv-cbt/`).
