# cv-cbt — «АБС: подключите модуль»

Интерактивное резюме под вакансию **«Инженер-программист»** ОАО «Центр банковских технологий» ([cbt.by/career](https://www.cbt.by/career/)).

Резюме работает как живая карта **автоматизированной банковской системы**: узлы-сервисы открывают панели, где проблема узла → навык кандидата → проект-доказательство. Сам кандидат — «модуль инженера-программиста» со статусом **не подключён**: healthcheck системы его находит и ведёт к CTA «Подключить модуль» (собеседование).

## Стек

- React 19 + TypeScript + Vite
- SVG-карта АБС без внешних библиотек (ноль runtime-зависимостей)
- Деплой: GitHub Pages (`base: /cv-cbt/`)
- Печать/PDF: статичный фоллбек всех разделов для HR

## Разработка

```bash
npm install
npm run dev      # локальный запуск
npm run build    # прод-сборка
npm run preview  # предпросмотр сборки
```

## Структура

- `src/data/` — весь контент резюме одним слоем: кандидат, навыки, проекты, узлы системы
- `src/components/` — карта, панели узлов, секции
- Политика честности: только проверяемый опыт; доказательства — публичные репозитории, дипломный проект представлен описанием (репозиторий приватный)
